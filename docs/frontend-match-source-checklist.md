## 1. 契约核对范围

契约权威来源是 `scripts/05_api.py` 的 `search_by_embedding`。本核对不把 README 中可能滞后的示例 JSON 当作权威。

### 1.1 字段定义原文

```text
744-                row = build_result(rank, 0.0, entry["meta"])
745-            row["rank"] = rank
746-            if video_id in keyword_text_by_id:

```

### 1.2 逐字段核对表

| 字段 | 响应位置 | 实现中的类型 | 合法取值或形态 | 何时出现 | 缺失时的真实含义 | 前端表现 |
|---|---|---|---|---|---|---|
| `match_type` | `data.results[]` 每一行 | Python `str` | `"semantic"`、`"keyword"`、`"both"` | 关键词分支实际执行时，由上面三处赋值写入；关键词通道关闭、空关键词调用或以图搜图时不写入 | 旧响应、关键词通道未执行或以图搜图；不是错误值 | 不渲染来源行，不猜测为 `semantic`，不显示空白占位 |
| `matched_text` | `data.results[]` 每一行 | Python `str` | 关键词命中时为实际命中的字符串片段；纯语义时为 `""` | 与 `match_type` 同一混合分支一起写入 | 旧响应、关键词通道未执行或以图搜图；不是 `null` 的固定契约 | `keyword`/`both` 且非空时显示中性“命中文字”；否则不渲染证据行 |

补充核对：

- `match_type` 和 `matched_text` 是每个结果对象的字段，不在 `data` 顶层。
- `build_result` 原有字段不需要由前端重命名；前端只消费新增字段并保留旧字段。
- `matched_text` 的具体字符串来自关键词搜索选中的命中片段；实现没有返回片段类型字段，因此前端不能区分文件名片段和目录名片段。
- `match_type=keyword` 或 `both` 时，按当前实现 `matched_text` 应为非空字符串；前端仍要对空串、null、非字符串和异常枚举做容错。
- `match_type=semantic` 时，当前实现写入 `matched_text=""`；前端不显示命中文字区。
- 字段缺失与空字符串必须分开处理：缺失表示没有新提示能力，空字符串表示当前结果没有关键词文字证据。

## 2. 可判定的验收清单

每一项都要求通过或失败，不使用“体验良好”“视觉统一”等主观描述。测试数据统一使用 `material_file_sample`、`parent_segment_sample` 等已填实的中性占位示例值。

### 2.1 契约与降级

- [ ] **C-01 结果位置**：构造一条包含 `data.results` 的响应，确认前端从每个结果对象读取字段，不从 `data` 顶层读取。失败条件：字段被错误地当成顶层字段。
- [ ] **C-02 三值映射**：`match_type` 为 `semantic`、`keyword`、`both` 时，分别显示“语义命中”“关键词命中”“两路命中”。失败条件：任一枚举缺失、错映射或显示原始枚举代替中文。
- [ ] **C-03 关键词文字**：`keyword` 且 `matched_text` 为 `material_file_sample` 时，显示“命中文字”和原字符串。失败条件：不显示、改变字符串或显示成文件名/目录名分类。
- [ ] **C-04 双路文字**：`both` 且 `matched_text` 为 `parent_segment_sample` 时，显示“两路命中”和原字符串。失败条件：来源徽标缺失或证据行缺失。
- [ ] **C-05 纯语义空值**：`semantic` 且 `matched_text` 为空字符串时，只显示来源徽标，不显示命中文字行、破折号或“未知”。失败条件：出现空行或占位文案。
- [ ] **C-06 字段缺失**：分别测试两个字段都缺失、只缺一个字段的响应。结果卡片、标题、缩略图、时长、分辨率、属性标签和操作区仍可见。失败条件：页面报错、卡片消失、出现骨架或来源空白框。
- [ ] **C-07 非法值**：`match_type` 为未知字符串、`matched_text` 为 null、数字或对象时，不抛出异常，不显示 `[object Object]`，省略异常提示并保留结果卡片。失败条件：页面崩溃或异常值出现在界面。
- [ ] **C-08 不误判缺失**：`match_type` 缺失但 `matched_text` 非空时，不显示命中来源或证据。失败条件：仅凭文字字段生成“关键词命中”。
- [ ] **C-09 以图搜图**：使用没有新字段的以图搜图响应，确认不显示来源徽标。失败条件：前端默认为 `semantic` 或显示“关键词命中”。
- [ ] **C-10 旧响应操作**：字段缺失时仍能预览代表帧、打开原片、复制路径并按原顺序展示。失败条件：任一既有操作被新提示阻断。

### 2.2 布局与视频级结果

- [ ] **L-01 独立来源行**：在 1440px、768px、320px 宽度检查，来源行位于标题之后、既有元信息行之前。失败条件：来源徽标进入时长/分辨率/属性标签组，或覆盖标题。
- [ ] **L-02 既有标签不冲突**：时长、分辨率、属性标签的数量、顺序和样式不因来源提示改变。失败条件：来源提示替换、重排或遮住任一既有标签。
- [ ] **L-03 窄屏换行**：320px 宽度下标题、来源行、命中文字和元信息均可读；允许换行但不能横向滚动。失败条件：出现裁切、重叠或不可操作区域。
- [ ] **L-04 视频级粒度**：响应含同一素材的多个代表帧数据时，列表仍只渲染一行素材，来源只出现一次。失败条件：同一素材重复多行或出现帧级来源列表。
- [ ] **L-05 排名不变**：改变来源徽标样式或主题后，结果顺序仍与响应中的 `rank` 一致。失败条件：前端按来源重新排序。

### 2.3 视觉与非颜色编码

- [ ] **V-01 文字冗余**：灰度截图或移除颜色后，三种状态仍能通过“语义命中”“关键词命中”“两路命中”文字区分。失败条件：只能靠色块辨认。
- [ ] **V-02 形状冗余**：三种状态分别使用眼睛/画面轮廓、标签/引号、双节点/分叉三类不同形状。失败条件：图标全部相同或只剩一个图标。
- [ ] **V-03 边框冗余**：`semantic` 为实线、`keyword` 为虚线、`both` 为实线，且三种状态不依赖边框颜色单独区分。失败条件：只改变边框颜色。
- [ ] **V-04 尺寸**：三种徽标字号为 12px、行高 16px、圆角 6px、内边距 4px 8px、最小高度 24px。失败条件：任一状态明显不一致或文字换行。
- [ ] **V-05 视觉权重**：计算样式中字重满足 `both` 700、`keyword` 600、`semantic` 500。失败条件：三者相同或 `semantic` 比双路状态更醒目。
- [ ] **V-06 颜色 token**：组件使用 source-semantic、source-keyword、source-both 的语义 token，不在组件中散写三套品牌色。失败条件：出现未定义的品牌专用颜色或只能在一套主题下工作。
- [ ] **V-07 对比度**：普通文字与底色对比度至少 4.5:1，边框与相邻底色至少 3:1；浅色和深色分别测量。失败条件：任一状态低于阈值。
- [ ] **V-08 图标可访问性**：图标标记为装饰性，读屏不会重复朗读图标；文字仍被读出。失败条件：图标单独朗读或文字被隐藏。

### 2.4 `matched_text` 边界

- [ ] **M-01 原样显示**：输入 `material_file_sample`，可见值必须逐字相同。失败条件：自动加扩展名、改大小写、补路径或改变空白。
- [ ] **M-02 不猜类型**：输入 `parent_segment_sample`，界面仍只显示“命中文字”，不显示“文件名”或“目录名”。失败条件：前端根据外观猜测类型并给出未经契约支持的标签。
- [ ] **M-03 不猜类型二**：输入没有扩展名和斜杠的长字符串，仍只显示“命中文字”。失败条件：因无法分类而隐藏原文。
- [ ] **M-04 桌面截断**：输入超过 64 个 Unicode code point 的中性字符串，可见结果为前 24 个、`…`、后 39 个。失败条件：只显示尾部、使用不同长度或改变原文内容。
- [ ] **M-05 窄屏截断**：输入超过 40 个 Unicode code point 的中性字符串，可见结果为前 15 个、`…`、后 24 个。失败条件：窄屏仍使用 64 字符规则或发生横向滚动。
- [ ] **M-06 完整值可访问**：视觉截断后，读屏可访问名称和可选 `title` 仍包含完整原字符串。失败条件：只能读取省略后的字符串。
- [ ] **M-07 空值不占位**：`matched_text` 为空、null 或非字符串时，不显示空证据框、破折号或“未知”。失败条件：出现空白行或错误对象文本。
- [ ] **M-08 纯文本安全**：输入包含 `<`、`>`、`&` 等字符的字符串时按文字显示，不生成 HTML 标签或执行内容。失败条件：出现解析后的标签、脚本或实体错乱。

### 2.5 无障碍与动效

- [ ] **A-01 可访问名称**：来源组的可访问名称分别能读出“命中来源：语义命中”“命中来源：关键词命中”“命中来源：语义与关键词均命中”。失败条件：只读出图标或只读出裸枚举。
- [ ] **A-02 非交互焦点**：徽标和命中文字默认不进入 Tab 顺序，原有预览、打开、复制操作仍可键盘访问。失败条件：新增元素制造焦点陷阱或阻断既有操作。
- [ ] **A-03 减少动效**：启用 reduced-motion 后来源区立即显示最终内容，不依赖动画结束才出现。失败条件：内容在减少动效模式下不可见或延迟。
- [ ] **A-04 深浅主题**：在浅色和深色主题各检查一次，三种来源文字、图标、边框均可读。失败条件：只改透明度导致文字融入背景。
